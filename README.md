# Cat Gunner Research H5

Playable web build reconstructed from the Cat Gunner source/evidence workspace.

- `npm run build` creates the production bundle.
- `npm run dev` starts the local preview.
- The default entry is the playable game; `debug.html` and `qa.html` are isolated research/debug surfaces.

This is a research playable build. Real ads, payments, cloud saves, and original-device parity are not connected.
